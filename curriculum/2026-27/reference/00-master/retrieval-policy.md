# Curriculum Retrieval Policy

## Source priority
When several sources are relevant, use this order:
1. Current dated daily lesson — controls today's assigned work.
2. Current teacher feedback/mastery evidence — controls pacing and reteaching.
3. Current subject syllabus/reference — controls course sequence and standards context.
4. Current unit guidance — controls prerequisite concepts, examples, misconceptions, and teaching approach.
5. Rubric/assessment guidance — controls quality criteria.
6. Academic history — background only; never overrides current evidence.

## Recency
Prefer current school-year and current-status documents. Historical records should be used only for continuity or when explicitly relevant.

## Student safety / assessment integrity
The student retrieval store must never contain unrestricted answer keys or protected independent-assessment answers. Daily curriculum is sanitized before vector ingestion. Protected answers remain in structured server storage and are accessed only through the controlled answer-support tool after an attempt.

## Search strategy
For ordinary lesson help, search using subject + unit + lesson concept + the pedagogical need, for example:
- mathematics + decimal operations + misconception + worked example
- literature + central idea + evidence + rubric
- french + regular ER verbs + negation + oral practice

Use subject filtering when a subject-specific result is needed. Search without a subject filter when looking for school-wide rules, mastery policy, or teacher behavior.

## Conflict handling
If a retrieved reference appears older or inconsistent with the current daily lesson, follow the daily lesson for today's assigned work and use the reference only for background. If two current sources conflict materially, do not invent a reconciliation; teach the safe/common foundation and note the conflict for the teacher/parent.

## Factual clarification
General model knowledge may be used to explain stable facts, vocabulary, or examples. It must not silently change the planned curriculum, grading rule, or recorded student history.
